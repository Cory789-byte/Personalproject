## THE RULES
- Completeness is never argued in the abstract — name the missing document, cite its proof.
- A list is an implicit representation of completeness. Every later-surfacing document
  (and the employment track guarantees there will be some) is priced against it.
- Curated-but-plausible disclosure still loses: whatever honest fraction arrives lands on
  pleaded particulars (the 9A/64G machine), and every gap remains order-enforceable with
  the sworn alternative. There is no volume of disclosure that discharges an ORDER except
  compliance with it.
